# Library Desktop Application

**Library Desktop Application** is an intuitive, all-in-one management system designed to automate administrative tasks for school, university, and public libraries. It simplifies book circulation, member records management, and inventory tracking within a user-friendly interface.

## Key Features

- **Book Catalog & Search:** Add, update, and search books by title, author, ISBN, or genre with real-time availability tracking.
- **Member Management:** Register library members (students, staff, or general public), manage membership tiers, and view borrowing histories.
- **Issue & Return System:** Process book checkouts and returns seamlessly with automated due-date tracking.
- **Fine & Overdue Management:** Automatically calculate late fees, mark unpaid penalties, and track overdue items.
- **Reporting & Analytics:** Generate detailed summaries of active loans, popular titles, and total inventory value.
